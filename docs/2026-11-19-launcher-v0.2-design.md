# .NET Launcher 0.2 — дизайн

Дата: 2026-11-19 · Основа: просьбы пользователя после публикации 0.1.0

## Что просил пользователь
1. Страницы модов, ресурспаков и шейдеров с фильтрами (популярное и т.д.).
2. При выборе мода справа открывается его страница: текст как на сайте, картинки, гифки.
3. Создание своих сборок: выбор версии Minecraft и загрузчика (Fabric, Forge, NeoForge); сборок может быть несколько.
4. Недостающие зависимости скачиваются вместе с модом (уже есть в 0.1, показать явно).
5. Вкладка «Друзья» как в Steam (заявки, «в сети», приглашения) через сервер пользователя; играть вместе.

## Решения
### Каталог (п. 1)
- Вкладка «Найти новые» становится каталогом: сортировка `Популярное` (загрузки), `Подходящее` (по запросу),
  `Новое`, `Обновлённое`; фильтр по категориям (Modrinth `/tag/category`, CurseForge `/categories`).
  Кнопка `Показать ещё` догружает по 20.
- Источник: Modrinth или CurseForge (как в 0.1).

### Страница мода справа (п. 2, 4)
- Список слева, панель справа (примерно 45 % ширины), открывается сдвигом.
- Шапка: иконка, название, автор, загрузки, категории. Кнопка `Установить`; под ней
  «Вместе с ним установятся: …» (обязательные зависимости, ещё не стоящие).
- Галерея: картинки ленты, клик открывает крупно.
- Текст: описание проекта (Modrinth `body` — Markdown; CurseForge `description` — HTML) в QTextBrowser;
  картинки и гифки из текста подгружаются в фоне, гифки анимируются (QMovie).
- Ссылки: страница проекта, исходники, Discord, если есть.

### Свои сборки (п. 3)
- На главной у переключателя сборок кнопка `Новая сборка`: название, версия Minecraft (только релизы,
  переключатель «показывать снапшоты» не нужен), загрузчик `Без модов / Fabric / Forge / NeoForge / Quilt`,
  версия загрузчика (последняя стабильная по умолчанию).
- Сборка создаётся локально (`instances/<id>`), ставятся Minecraft, загрузчик и Java. В каталог попадает только
  после публикации автором (как в 0.1).
- У каждой сборки свои моды, снимки, миры.

### Друзья (п. 5) — ждёт ответов про сервер
- Нужна служба лаунчера на сервере пользователя: аккаунты по Ely.by (без паролей: лаунчер делает `join`,
  служба проверяет `hasJoined` у Ely.by), заявки в друзья, статус «в сети / играет в <сборка> / на сервере»,
  приглашения «Играть вместе» (подключение к Minecraft-серверу сборки).
- Вопросы к пользователю: что за сервер (ОС, есть ли домен/белый IP), можно ли открыть порт для службы,
  где сейчас Minecraft-сервер.

## Порядок
1. Каталог с фильтрами + страница мода справа.
2. Свои сборки.
3. Друзья (после ответов).
