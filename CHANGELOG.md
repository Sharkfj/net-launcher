# .NET Launcher 0.3.5

- Open the mod catalog directly from a compatible pack on the home screen or in the pack list. Install mods and their dependencies from search results in one click.
- Shared packs show their Minecraft version, loader and file count in chat. Before installation, review the expected download size and files that need to be added manually.
- An invitation can start installation of the matching official pack or open the sender's chat. The launcher continues joining after the requested pack is ready and can restore missing files in shared packs.
- Create a separate test copy of a pack. Copy worlds only if you select the option.
- Copy a crash report with the Minecraft, loader and Java versions, exit code and Java exception classes.
- Use the download button next to the launcher version to check GitHub for a newer release and download the matching Windows or Linux installer.
- CurseForge downloads can use the configured friends Worker for mods, dependencies and chat packs. Players signed in through Ely.by do not need their own CurseForge key.

# .NET Launcher 0.3.2 beta 2

## Packs and worlds

- Open **Packs** to manage installations. Each pack has its own mods, shaders, resource packs, screenshots and worlds.
- Enable **FPS mode** when creating a personal pack to use a 10-chunk render distance and install performance mods compatible with its loader and Minecraft version.
- Restore a world from one of its five most recent backups. Official packs also back up worlds before an update and check their files before launch.
- Use the compact version picker to select Minecraft and loader versions inside the launcher.

## Profiles and friends

- Open your profile from the player head in the sidebar. Account skins appear in the launcher when available. A plain gray model is shown if no skin loads.
- Preview nickname fonts, colours, shimmer and pulse effects, and avatar frames. A supporter key unlocks saving cosmetics, including for players with no personal packs. The developer account has a hammer badge.
- Choose who may comment on your profile. Profile owners can remove any comment, and authors can remove their own.
- Open direct and group chats inside **Friends** to share screenshots and pack invitations. Chat, online comments and cosmetic sync need a compatible friends service.

## Desktop integration

- The Windows installer adds Start menu and desktop shortcuts. The x86_64 Linux installer adds a launcher to the application menu and installs under the current user's account.

- Linux downloads include an x86_64 AppImage for common desktop distributions, alongside the standalone archive. The AppImage requires a compatible glibc; it cannot cover every Linux system or CPU architecture.
- Discord Rich Presence can show the launcher logo, the active pack and time played. The application ID is built in. Use **Settings → Discord activity** to switch it off.
- Updated the desktop and tray icons and added an animated startup sequence. The interface supports English and Russian.

This release updates the Windows and Linux launchers. The official .NET modpack remains at version 0.1.0.
